# Mindful Cart

Mindful Cart is a Chrome extension concept for more intentional online shopping. Before checkout, it gives shoppers a concise, animated summary of items that may deserve a second look, such as a lower-priced store-brand option, a recent similar purchase, or a supported health concern.

The extension offers information and suggestions only. Shoppers decide whether to change their cart or continue with the purchase. It does not connect to personal financial accounts or control checkout.

See the [product requirements document](docs/PRD.md) for the product goals, user journey, evidence standards, and hackathon MVP scope.
